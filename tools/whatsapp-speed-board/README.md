# FCUNO WhatsApp Speed Board

Local Chrome extension for the trading-hour WhatsApp workflow.

## Purpose

- No Meta WhatsApp API.
- No FCUNO phonebook search.
- No template sending.
- No webhook or message sync.
- Each trader keeps their own Supplier and Buyer board on their own WhatsApp Web session.

## Install For Testing

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Enable `Developer mode`.
4. Click `Load unpacked`.
5. Select this folder:
   `/Users/hocheunglai/Desktop/bunker-map/tools/whatsapp-speed-board`
6. Open `https://web.whatsapp.com`.

## Trading Use

- Add current chat to Supplier or Buyer.
- Or manually add a name and optional phone number.
- Drag contacts to reorder.
- Click a contact to jump to the WhatsApp chat.
- Everything is stored locally in the trader's browser under `fcuno-wa-speed-board-v1`.

## Notes

This extension does not auto-send messages. It only helps organize and open chats inside the trader's own WhatsApp Web session.
